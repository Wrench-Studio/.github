# Support

This is a small hobby studio, not a help desk — please set
expectations accordingly. 🙂

## Best places to start

1. The project's **README** for setup and usage.
2. The repo's **Issues** tab — someone may have asked already.

## For bugs

Open an issue with a short description. Screenshots or logs help.

## For something private

Email: `your-email@example.com`

## A note

I read everything but I can't promise fast replies. If something is
urgent and broken, fork it and fix it — PRs are welcome.
