# Code of Conduct

This is a small hobby project, so the bar is simple:

- Be kind. Disagree on ideas, not on people.
- No harassment, no personal attacks, no doxxing.
- Assume good faith; ask before you assume the worst.

That's it. The full Contributor Covenant is great for big projects,
but it's overkill here — for a hobby studio, "don't be a jerk" covers
it.

If something feels off, you can reach me at `your-email@example.com`.
