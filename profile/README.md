# 🔧 Wrench-Studio

> An indie development studio — building practical software, tools, and games.

## 👋 About

**Wrench-Studio** is a small, independent software studio. We maintain a focused
collection of open-source projects here on GitHub, ranging from backend services
and self-hosted infrastructure to games and developer tools.

Our projects are built with care, documented in-repo, and released for hands
up to the community.

## 🛠️ What we work on

| Area | Examples |
| --- | --- |
| **Backend services** | Go-based servers, REST/RPC services |
| **Self-hosting & networking** | LAN tools, home-lab projects |
| **Games & tooling** | Game servers and related infrastructure |
| **Developer utilities** | Small scripts, CLI tools, libraries |

Browse the 📦 **Repositories** tab for the full list — each project has its
own README with build and run instructions.
